### 🧠 SkillSync AI — Agentic Resume Intelligence Platform
*Production-Oriented Hybrid RAG & Candidate Matching Engine*

**Problem** — Candidates need honest, evidence-based resume feedback; recruiters need fast, defensible ranking across large applicant pools.
**Solution** — A hybrid dense + lexical retrieval layer feeds a deterministic, hallucination-resistant LLM scoring engine.

- **Hybrid Retrieval:** Combines dense semantic retrieval (`pgvector`) with lexical keyword scoring (`Apache Solr`) over 1,000+ chunked documents, driving a **40% reduction in retrieval latency**.
- **Deterministic Scoring:** Structured LLM orchestration scores applicants on missing competencies, keyword relevance, and contextual evidence without hallucinations.
- **Microservices:** 12 decoupled FastAPI modules with JWT authentication, PostgreSQL persistence, Redis caching, and containerized Docker Compose deployment.

```mermaid
flowchart LR
    Candidate[Candidate / Recruiter] --> API[FastAPI Gateway]
    API --> Auth[JWT Security]
    Auth --> Retrieval{Hybrid Retrieval Layer}
    Retrieval -->|Dense Vectors| VDB[(PostgreSQL + pgvector)]
    Retrieval -->|Lexical Match| Solr[Apache Solr]
    VDB --> Ranker[LLM Synthesis & Scoring]
    Solr --> Ranker
    Ranker --> Output[Candidate Intelligence Dossier]
```

**Stack:** `Python` `FastAPI` `PostgreSQL` `pgvector` `Apache Solr` `Redis` `LangChain` `Docker` `JWT`
