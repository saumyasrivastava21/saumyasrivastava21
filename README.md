```mermaid
flowchart LR
```

### AI-Powered Medical Imaging Analysis & Intelligent Reporting Platform

A full-stack medical AI platform that takes a clinical image through detection, analysis and agentic report generation into a structured, safety-validated medical report.

**Capabilities**
- Multi-model medical image analysis — skin cancer classification, pneumonia classification, brain tumor detection, bone fracture detection
- YOLO-based object detection and classification models
- FastAPI AI inference service behind an Express backend and React frontend
- AI-generated medical report layer powered by NVIDIA Nemotron
- Agentic report orchestration: finding analyzer → evidence agent → safety validator
- Structured report generation with PDF export
- Dashboard with report history and an AI chatbot
- End-to-end image upload and inference workflow with MongoDB persistence and authentication

**Architecture**

```mermaid
flowchart TB
    A[React Frontend] --> B[Express Backend]

    C --> D[ML Models]
    D --> E[Structured Predictions]

    F --> G[Evidence Agent]
    G --> H[NVIDIA Nemotron LLM]
    H --> I[Safety Validator]
    I --> J[Structured Medical Report]
    J --> K[(MongoDB)]
    J --> L[Dashboard / PDF Report]
```

**Tech Stack**

`React` `Express` `FastAPI` `MongoDB` `YOLO` `PyTorch`
